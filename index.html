知网 PDF 命名助手

隐私政策 · 版本 1.0.0 · 更新日期 2026-10-08

适用范围

本隐私政策适用于在 Microsoft Edge 中使用的“知网 PDF 命名助手”1.0.0。发布者提供的支持邮箱为 wangk109925@126.com。本扩展是独立的文献整理工具，与中国知网没有官方隶属或授权关系。

访问和处理的信息

扩展在 cnki.net 及其子域名页面中读取文献题名、作者及单位信息、作者单位编号、期刊、出版年份、详情页网址和 PDF 下载链接，用于提取第一作者及其对应单位、核对信息和生成文件名。用户自行输入的修正信息也在本地处理。扩展不读取 PDF 正文、Cookie、密码、付款资料或登录表单。

浏览器下载信息

为建议新下载的文件名，扩展接收 Microsoft Edge 下载事件提供的元数据，包括原文件名、文件类型、下载网址、最终网址及来源网址，并仅使用与文献关联和命名所需的字段。浏览器的下载事件可能同时包含其他下载；无法确认关联到知网文献的下载不进行命名，也不保存为本扩展的文献或命名记录。扩展不主动查询浏览器完整下载历史，不扫描已有本地文件。

用途和存储位置

信息只用于当前文献核对、下载关联、PDF 文件名生成、最近命名结果展示及用户设置。简称表、开关、分隔符、长度上限和子文件夹设置使用扩展本机存储（storage.local），不使用浏览器同步存储（storage.sync）。当前文献信息、修正、下载关联记录和最近命名结果使用浏览器会话存储（storage.session）。下载链接中的网站参数仅用于本地关联，不发送给开发者。

保留期限

简称与规则设置保留到用户修改或移除扩展。关闭详情页会清除该页的文献记录，但尚待匹配的下载快照和最近结果可能仍保留在会话中。下载快照超过 10 分钟、空闲文献记录超过 30 分钟后不再用于自动关联；这些时间是关联有效期，不代表到期立即删除所有存储条目。会话数据在浏览器会话结束或由 Microsoft Edge 清除扩展会话存储时清空。

对外传输和第三方

扩展代码不向开发者或其他服务器发送文献、网址、下载记录或设置，不含广告、统计分析、遥测或远程执行代码，也不出售、共享或用这些信息进行广告画像。用户通过知网原有流程访问和下载全文时，网站与 Microsoft Edge 自身的数据处理由其各自政策约束。若隐私政策网页托管于第三方平台，访问该网页产生的服务日志由该平台处理，扩展本身不向该网页附加用户数据。

你的控制方式

你可以在核对界面查看、修改本篇文献信息，在设置中编辑简称或恢复默认设置后保存。“开启自动命名”开关只控制下载命名；如需停止扩展访问页面和接收下载事件，请在 Edge 扩展管理页禁用或移除扩展。退出浏览器可结束会话存储；移除扩展可清除其设置。扩展无法删除已下载的文件、已导出的设置备份、浏览器下载历史或已复制的剪贴板内容，这些内容由你自行管理。

权限说明

downloads：接收新下载事件并建议文件名。storage：保存本机设置和会话信息。activeTab：用户点击扩展图标时识别当前标签页并与该页交互。cnki.net 页面访问：在匹配的页面运行内容脚本，读取文献元数据并显示核对界面。上述访问仅用于所述文献命名功能。
